# CSCE 5310 Data Visualization: U.S. Vice Presidents by Age

Discussion #3, Item 1 for CSCE 5310 at the University of North Texas. The data comes from Wikipedia's "List of vice presidents of the United States by age" and is embedded in the script as a CSV string.

- `colab_vp_visualizations.py`: Python code (pandas, matplotlib, seaborn) written to be pasted into Google Colab cells. It computes each vice president's age at the start of their term and draws charts of the results.
- `Item1_VP_Age_Visualizations.pdf`: the write-up showing the code cells with their outputs and charts.
